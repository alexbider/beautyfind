The ranking changes made during the review (all in `src/lib/import/categoryRank.ts`, shared with the import pipeline):

- Google's additional types score once per category, however many labels map to it.
- The audit compares the primary type by id, so it is no longer scored a second time as an additional type (`scripts/import/categoryAudit.ts`).
- Name hints are ordered by where the word appears in the name; the first word wins.
- New hints: hair salons (החלקה, תוספות שיער, פאות), dental (דנטל), facials (קוסמטי, cosmet), medical aesthetics (נגעי עור, הסרת שומות, נקודות חן), permanent makeup (איפור גבות, איפור שפתיים, מיקרופיגמנטציה). The plain makeup hint no longer matches those permanent-makeup phrases.

- The OpenAI account has no credits. The first listing of batch 1 got a draft at 15:43; from the second listing (15:56) onwards every entry says `editorial: no_credit: You have no credits remaining`. A draft replaces existing text only when it is complete: at least 120 words, at least 3 FAQs, not flagged, no text-rule violations (`editorialComplete` in `src/lib/server/importPublish.ts`). A shorter draft only fills an empty field, so this one was stored on the listing's editorial record but not published.
