# Complete profile import: what was built, tested and measured

Commit `b6c8339` on `main`. Design source: `Copy of MedSpaFind platform design.zip` (desktop `BeautyFind Business Profile.dc.html`, `Mobile v2`, `handoff/Business Profile Mobile v2.md`, `02-data-model.md`). Sample arrays in the template scripts (prices, FAQs, staff, reviews, promises, `demo1` videos) were treated as fixtures only; none of that text ships.

## Tested

- `npm run test:import`: 116 tests pass (the Apify suite of 17 was added on 2026-09-27) (unit, database, and the new `tests/import/profile.test.ts` covering acceptance points 1 to 8 and the SSRF-safe fetch path). Mocked providers only.
- Simulated 10-business pilot (`npm run import:simulate`, report in `docs/import-pilot-SIMULATED.md`): rich clinic sites, a two-branch chain, a site without prices, sparse listings without a site. Rich profiles: 11 services (3 without a published price, 0 zero-priced), 8 copied photos, 2 playable videos, 3 team members from the site, 0 staff logins created, 8 FAQs, readiness 82%. Sparse: `needs_owner_information`, short draft flagged. Descriptions came from the deterministic template (mock); with the API the Sonnet call produces the 450 to 550 words.
- Production build and local `next start`: the listing renders with all sections; JSON-LD checked (11 offers, 8 with a price specification, verified sameAs, FAQ page, no aggregate rating from Google). Screenshots at 390, 768 and 1440px (full page, lightbox, contact flow, mobile sticky bar) were taken locally from the simulated data with `npm run import:screenshots`; they are not committed.
- Not performed: any live API call (DataForSEO, Anthropic, YouTube, Google Maps). No real scrape happened and no money was spent.

## Costs (reference rates, gross)

Per fully enriched profile: DataForSEO about $0.0004 (discovery share), editorial about $0.06 to $0.075 (Sonnet, one repair in four), YouTube 0 to 3 quota units (no charge), Maps Embed no charge, storage about 3 MB (six WebP derivatives plus originals). The discovery price alone is never reported as the profile cost. Estimator rows (defaults): 100 profiles about $3.9, 1,000 about $39, 10,000 about $390, dominated by editorial writing; Haiku 4.5 lowers that several times.

## Missing configuration

- `OPENAI_API_KEY` (GitHub secret): without it the research tasks are skipped and the ChatGPT writer stops with `no_api_key`; listings keep their source text.
- `ANTHROPIC_API_KEY` (GitHub secret, optional): only when the writer is switched to Claude.
- `NEXT_PUBLIC_GOOGLE_MAPS_EMBED_KEY` (Vercel): browser key restricted to our domains and the Maps Embed API.
- `YOUTUBE_API_KEY` (GitHub secret, optional): channel discovery and exact embeddability; oEmbed covers videos found on the site without it.
- `BLOB_READ_WRITE_TOKEN` (GitHub secret, optional): lets the worker copy images during enhance runs; the admin copy button covers it otherwise.

## Genuine data gaps

- Before/after images are never imported; they wait for the owner's consent record.
- Team size, languages and founding year appear only when a source states them.
- Verified credentials and the מאומת badge come only from our verification workflow.
- Reviews from Google are a summary and a link; review texts are not copied.
